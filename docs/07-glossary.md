# 📖 Glossary — තාක්ෂණික වචන සිංහලෙන්

> ලේඛන කියවද්දී තේරෙන්නේ නැති වචනයක් තිබුණොත් මෙතන බලන්න.

---

## මූලික සංකල්ප

| වචනය | සරල අර්ථය |
|---|---|
| **Industry 4.0** | කර්මාන්තශාලා automate කිරීමේ අදියර. Sensors, IoT, දත්ත, robots. **ඉලක්කය = කාර්යක්ෂමතාව.** |
| **Industry 5.0** | ඊළඟ අදියර. තාක්ෂණය **මිනිසාට උදව් කිරීම** සඳහා. **ඉලක්කය = මිනිසා + පරිසරය + කාර්යක්ෂමතාව.** |
| **Digital Twin** | සැබෑ දෙයක (machine/මිනිසෙක්) **සජීවී virtual පිටපත**. සැබෑ එක වෙනස් වුණාම මේකත් ඒ මොහොතේම වෙනස් වෙනවා. |
| **Human Digital Twin (H-DT)** | සේවකයාගේ **වැඩට අදාළ තත්ත්වයේ** virtual model එකක් — වෙහෙස, දක්ෂතාව, ඉරියව්ව. (පෞද්ගලික දත්ත **නොවේ**.) |
| **Machine Digital Twin (M-DT)** | යන්ත්‍රයේ virtual පිටපත — සෞඛ්‍යය, බලශක්තිය, ගුණාත්මකභාවය. |
| **Smart Manufacturing** | දත්ත + software යොදාගෙන "බුද්ධිමත්ව" ක්‍රියාත්මක වන නිෂ්පාදනය. |
| **Framework** | සියල්ල එකට සම්බන්ධ කරන **ව්‍යුහගත ආකෘතිය** — layers, components, දත්ත ගලායාම, ඇගයීම. |
| **Sustainability** | තිරසාරභාවය — බලශක්තිය, කාබන්, අපද්‍රව්‍ය අඩු කිරීම. |
| **Triple Bottom Line** | People (මිනිසා) · Planet (පරිසරය) · Profit (ලාභය) — තුනම එකවර සැලකීම. |

## AI / ML වචන

| වචනය | සරල අර්ථය |
|---|---|
| **Model** | දත්ත වලින් ඉගෙනගෙන පුරෝකථනය කරන ගණිතමය "යන්ත්‍රයක්". |
| **Train** | Model එකට දත්ත පෙන්නලා ඉගැන්නීම. |
| **XGBoost** | ජනප්‍රිය, ශක්තිමත් ML algorithm එකක් (tables වලට හොඳම). |
| **Random Forest** | තවත් ML algorithm එකක් — tree ගොඩක් එකට. |
| **LSTM** | Time-series (කාලය අනුව වෙනස්වන) දත්තවලට හොඳ neural network එකක්. |
| **RUL** | *Remaining Useful Life* — යන්ත්‍රය තව කොපමණ කාලයක් වැඩ කරයිද. |
| **Predictive Maintenance** | කැඩෙන්න කලින් අනාවැකි කියලා අලුත්වැඩියා කිරීම. |
| **XAI (Explainable AI)** | AI තීරණයක් **ඇයි** ගත්තේද කියා මිනිසාට තේරෙන ලෙස පැහැදිලි කිරීම. |
| **SHAP** | XAI කරන ජනප්‍රිය ක්‍රමයක් — "මේ තීරණයට කුමන සාධකය කොපමණ බලපෑවාද". |

## Optimization වචන

| වචනය | සරල අර්ථය |
|---|---|
| **Objective function** | "හොඳ" කියන්නේ මොකක්ද කියා ගණිතයෙන් ලියන සමීකරණය. අපි මේක **අවම** (minimize) කරනවා. |
| **Multi-objective** | ඉලක්ක **එකකට වඩා** එකවර. (උදා: fatigue අඩු + throughput වැඩි) |
| **Trade-off** | ගනුදෙනුව. එකක් හොඳ කරන්න අනිත් එක ටිකක් අත්හරින්න වෙනවා. |
| **Pareto front** | හොඳම trade-off විකල්ප රේඛාව. මේකෙන් එහාට යන්න බෑ — එකක් හොඳ කරන්න අනිත් එක නරක් වෙනවා. |
| **NSGA-II** | Multi-objective optimization කරන ප්‍රසිද්ධ algorithm එකක්. Pareto front එකක් දෙනවා. |
| **Constraint** | නීතියක් / සීමාවක්. **Hard** = කඩන්න බෑ. **Soft** = කැඩුවොත් දඩයක්. |
| **Weight (w)** | එක් එක් ඉලක්කයට කොපමණ වැදගත්කමක් දෙනවාද යන්න. |
| **Normalization** | විවිධ ඒකක (kWh, පැය, ලකුණු) එකම පරාසයකට (0–1) හැරවීම — එකට එකතු කරන්න. |

## Simulation වචන

| වචනය | සරල අර්ථය |
|---|---|
| **Simulation** | Computer එකේ ඇත්ත තත්ත්වය අනුකරණය කිරීම. |
| **Discrete-event simulation** | සිදුවීම් එකින් එක සිදුවන ආකාරයේ simulation (task පටන් ගන්නවා → ඉවර වෙනවා → ඊළඟ එක). |
| **SimPy** | Python වලින් discrete-event simulation කරන නොමිලේ library එකක්. |
| **Co-simulation** | කොටස් **දෙකක්** (machine පැත්ත + human පැත්ත) එකට run කිරීම. |
| **Seed** | Random අගයන් හදන ආරම්භක අංකය. එකම seed = එකම ප්‍රතිඵලය (reproducible). |
| **Replication** | එකම experiment එක **නැවත නැවත** run කිරීම (අපි 30ක්). |
| **Baseline** | සංසන්දනය සඳහා පාවිච්චි කරන "පවතින ක්‍රමය". |

## Human factors වචන

| වචනය | සරල අර්ථය |
|---|---|
| **Fatigue** | වෙහෙස. කාලයත් සමඟ වැඩි වෙනවා, විවේකයෙන් අඩු වෙනවා. |
| **Ergonomics** | ශරීරයට හිතකර ලෙස වැඩ පරිසරය සැලසුම් කිරීම. |
| **RULA** | *Rapid Upper Limb Assessment* — ඉරියව්ව අවදානම මනින ලකුණු ක්‍රමයක් (1 = ආරක්ෂිත, 7 = අවදානම්). |
| **Cognitive load** | මානසික බර — මොළයට කොපමණ වැඩක් තියෙනවාද. |
| **NASA-TLX** | Workload මනින ප්‍රසිද්ධ questionnaire එකක්. |
| **Operator 4.0 / 5.0** | තාක්ෂණයෙන් සවිබල ගැන්වූ සේවකයා පිළිබඳ සංකල්පය. |
| **Human-in-the-loop** | අවසන් තීරණය මිනිසා ළඟ තබාගැනීම. |
| **Override** | AI තීරණය මිනිසාට වෙනස් කරන්න පුළුවන් වීම. |

## KPI වචන

| වචනය | සරල අර්ථය |
|---|---|
| **KPI** | *Key Performance Indicator* — ප්‍රධාන කාර්යසාධන දර්ශකය. මනින දේ. |
| **Throughput** | නියමිත කාලයක නිෂ්පාදනය කරන ඒකක ගණන. |
| **Downtime** | යන්ත්‍රය නවතින කාලය. |
| **OEE** | *Overall Equipment Effectiveness* = Availability × Performance × Quality. |
| **Scrap rate** | දෝෂ සහිත නිෂ්පාදන ප්‍රතිශතය. |
| **CO₂e** | කාබන් ඩයොක්සයිඩ් සමානතාව — පරිසර බලපෑම මනින ඒකකය. |
| **Gini coefficient** | අසමානතාවය මනින ක්‍රමයක් (අපි වැඩ බෙදීමේ සාධාරණත්වයට පාවිච්චි කරනවා). |

## සංඛ්‍යානමය වචන

| වචනය | සරල අර්ථය |
|---|---|
| **Mean ± std** | සාමාන්‍යය සහ එහි විසිරීම. 30 runs වලින් ගණනය කරනවා. |
| **p-value** | "මේ වෙනස අහම්බෙන් සිදුවෙන්න තිබූ සම්භාවිතාව". **p < 0.05** = සැලකිය යුතුයි. |
| **Mann-Whitney U** | කණ්ඩායම් දෙකක් සංසන්දනය කරන test එකක් (දත්ත normal නොවුණත් වැඩ කරනවා). |
| **Effect size** | වෙනස කොපමණ **ලොකුද** කියන එක (p-value කියන්නේ ඒක තියෙනවාද කියන එක විතරයි). |
| **Statistically significant** | සංඛ්‍යානමය වශයෙන් සැලකිය යුතු — අහම්බයක් නොවේ. |
| **Bonferroni correction** | Test ගොඩක් කරනවා නම් p-value සීමාව දැඩි කිරීම. |

## ලේඛන / ප්‍රකාශන වචන

| වචනය | සරල අර්ථය |
