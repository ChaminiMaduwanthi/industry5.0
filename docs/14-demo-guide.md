# 💬 කොටස 3 · අහන ප්‍රශ්න 6ට උත්තර

### ❓ *"මේ සීමා අගයන් කොහෙන්ද? (0.80, 0.40)"*
> **HC3** (ඉරියව්ව ≤ 5) **RULA action level** එකෙන් — සාහිත්‍යයෙන්.
> අනිත් **තුන අපේ තෝරාගැනීම්**. ඒත් **HC1 එක 0.70 / 0.80 / 0.90** කරලා බැලුවා —
> **තුනේම එකම නිගමනය**. ➜ *"අංකය මත රඳා පවතින්නේ නෑ."*

### ❓ *"වෙහෙසේ ආකෘතිය ඔබ හදාගත්තද?"*
> **නෑ** — **Calzavara et al. (2019)** ගේ ප්‍රකාශිත ආකෘතිය.
> පුද්ගලික අගය **Mifflin (1990)** සහ **Price (1990)** සමීකරණවලින්.
> ⚠️ වේග දෙකක් (λ, μ) විතරයි අපේ — ඒවා **0.5×, 1×, 2×** කරලා පරීක්ෂා කරලා තියෙනවා.

### ❓ *"Industry 4.0 එක දුර්වල කරලා නැද්ද?"*
> **නෑ. එකම simulator එක, එකම code එක.** යන්ත්‍ර twin එක **පූර්ණ බලයෙන්**.
> යන්ත්‍ර සීමාවත් තියෙනවා. **එකම වෙනස: මිනිසා ගැන බලන්නේ නෑ.**

### ❓ *"ඇත්ත කර්මාන්තශාලාවක කළාද?"*
> **නෑ — simulation එකක්.** ඒත් **සංඛ්‍යා ඇත්ත datasets 3කින්**.

### ❓ *"ඔබේ අලුත් දේ මොකක්ද?"*
> **දෙකයි:**
